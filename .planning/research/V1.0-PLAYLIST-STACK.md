# Playlist Playback Stack Research

**Milestone:** v1.0 Playlist Playback & Management  
**Researched:** 2026-10-10  
**Confidence:** MEDIUM

## Recommended Stack

| Existing component | Role | Recommendation |
|--------------------|------|----------------|
| Home Assistant media-player and media-source APIs | Provider browsing and media resolution | Reuse `async_browse_media`, `async_resolve_media`, and `async_process_play_media_url`; add no provider-specific client. |
| BL-HAOS native integration | HA entity behavior and source identity | Keep HA media identifiers on the HA side; the integration already has access to `hass` and resolves media-source IDs. |
| BL-HAOS FastAPI bridge | Audio process and speaker control | Extend the existing authenticated native command/state boundary for ordered playback; keep URL validation in force. |
| Existing React ingress UI | Playlist authoring and playback selection | Reuse the current frontend and add a supported HA-side catalog bridge; it currently talks only to add-on REST/WebSocket endpoints. |

No additional runtime package is indicated by the evidence gathered. Home Assistant's media-player documentation demonstrates the browse/resolve pattern but is marked incomplete; validate exact APIs against the project's supported Home Assistant versions during phase planning.

## Alternatives Considered

| Recommendation | Alternative | Trade-off |
|----------------|-------------|-----------|
| Store stable Home Assistant media references and resolve at playback time | Persist resolved stream URLs | URLs may expire, contain access details, or become unreachable; identifiers preserve provider ownership. |
| Let the bridge own per-speaker sequential process lifecycle | Let the ingress UI issue one-off play commands | UI-driven advancement is fragile when the tab closes or network drops. |
| Add no media-provider SDK | Integrate directly with each provider | Direct clients duplicate authentication and provider-specific behavior already owned by HA. |

## Compatibility and Sources

- `MediaPlayerEntityFeature.BROWSE_MEDIA`, `async_browse_media`, and media-source resolution are documented at https://developers.home-assistant.io/docs/core/entity/media-player/ . The page is marked incomplete.
- Current integration implementation: `BL-HAOS-Integration/custom_components/bl_haos/media_player.py`.
- Current ingress API client: `modules/bridge/web_ui/src/api/client.ts`.
- Current backend playback implementation: `modules/bridge/backend/bl_haos/ha/player.py`.
- No supported HA version range or storage helper contract was established by this research; verify those before implementation.
