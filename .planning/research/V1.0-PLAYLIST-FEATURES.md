# Playlist Playback Feature Research

**Milestone:** v1.0 Playlist Playback & Management  
**Researched:** 2026-10-10  
**Confidence:** MEDIUM

## Feature Landscape

### Table Stakes

| Feature | Why expected | Complexity | Evidence / note |
|---------|--------------|------------|-----------------|
| Browse HA media providers from a BL-HAOS player | Users expect the native HA media browser to expose supported sources | Medium | HA documents `BROWSE_MEDIA` and `async_browse_media` delegating to `media_source.async_browse_media`. |
| Play provider playlists | A discovered playlist must start on the selected Bluetooth speaker | Medium | Existing `async_play_media` resolves media-source IDs but rejects enqueue requests. |
| Create and maintain saved playlists | User selected custom ingress playlists as well as provider playlists | Medium | Saved entries should be ordered HA media references, not copied media URLs. |
| Sequential playback and automatic advancement | A playlist should continue after the current item finishes | High | The backend currently runs one FFmpeg URL and marks the player idle when processes exit. |
| Preserve playback truth across failure and restart | Users need to know which item is active and whether a queue stopped | Medium | Current bridge state reports playback state and timeline, but no queue or playlist identity. |

### Defer Unless Explicitly Added

- Shuffle, repeat modes, queue editing during playback, and multi-speaker synchronized playlist control.
- Direct credentials or API clients for individual music providers.
- Persisting resolved URLs or provider tokens in either the add-on or playlist metadata.

## Dependencies

```text
HA media-source browsing and stable IDs
    -> secure ingress catalog access and saved playlist authoring
    -> HA-side media resolution at play time
    -> per-speaker bridge queue and process-completion handling
    -> playback state, cancellation, and recovery behavior
```

**MVP:** Browse and launch provider playlists in Home Assistant; create, edit, reorder, save, and delete custom lists of HA media references in ingress; play each saved list sequentially with automatic advancement.

**Research gap:** Whether provider playlist IDs resolve to a single playable stream or require item-by-item traversal depends on the provider. Do not assume all providers expose the same playlist shape.
