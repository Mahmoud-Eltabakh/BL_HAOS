# Plan 07-01: Home Assistant MQTT Discovery Payload Generator & Client

## Goal

Implement the Home Assistant MQTT Discovery publisher in `backend/bl_haos/ha/mqtt.py` that automatically generates standard `media_player` discovery payloads, state topics, and command subscriptions when speakers connect.

## Must Haves

1. `MqttDiscoveryManager` generating valid Home Assistant MQTT Discovery payloads (`homeassistant/media_player/bl_haos_{mac}/config`).
2. Discovery schema including `command_topic`, `state_topic`, `volume_command_topic`, `volume_state_topic`, and device registry metadata.
3. Clean unpublishing (empty payload with `retain: true`) when devices are deleted.
4. Automated pytest test suite `tests/test_mqtt_discovery.py`.
