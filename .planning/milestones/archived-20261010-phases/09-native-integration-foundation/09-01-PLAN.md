## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Home Assistant administrator to config flow | An administrator-provided endpoint controls where Core opens native transport connections. |
| Add-on container to Home Assistant configuration mount | The add-on writes the packaged custom component into a user-managed mount. |
| Add-on data credential to custom integration runtime | A shared credential authorizes Core-to-add-on native bridge requests. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-09-03 | I | Bridge credential | medium | mitigate | Generate once under the add-on data directory, restrict file permissions, and avoid emitting its value in logs or config-flow translations. |

</threat_model>
