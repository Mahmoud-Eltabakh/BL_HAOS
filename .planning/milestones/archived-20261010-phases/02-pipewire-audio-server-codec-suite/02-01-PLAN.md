# Plan 02-01: PipeWire Audio Server Core Config & S6 Longrun Supervision

## Goal

Configure the core PipeWire audio daemon with clock/buffer properties and establish S6-Overlay v3 longrun service definitions for `10-pipewire` and `20-wireplumber` with strict dependency chaining.

## Must Haves

1. `rootfs/etc/pipewire/pipewire.conf.d/10-clock.conf` defines `default.clock.rate = 48000`, `default.clock.quantum = 1024`, `min-quantum = 512`, `max-quantum = 2048`.
2. S6 longrun services `10-pipewire` and `20-wireplumber` are created with `type=longrun` and proper `dependencies.d/` links ensuring sequential startup.
3. Both service `run` scripts export `PIPEWIRE_RUNTIME_DIR=/var/run/pipewire` and `XDG_RUNTIME_DIR=/var/run/pipewire`.
4. Automated pytest test suite `tests/test_pipewire_s6.py` verifies service layout and dependencies.
