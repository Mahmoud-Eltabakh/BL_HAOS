# Plan 02-02: WirePlumber Bluetooth Codec Ranking, Low-Latency Tuning & AVRCP Volume Sync

## Goal

Configure WirePlumber SPA Bluetooth policy to prioritize high-resolution codecs (LDAC, aptX HD, aptX, AAC, SBC-XQ, SBC), enable bidirectional AVRCP hardware volume sync, and validate audio configuration with automated tests.

## Must Haves

1. `rootfs/etc/wireplumber/wireplumber.conf.d/50-bluez.conf` defines codec list: `ldac`, `aptx_hd`, `aptx`, `aac`, `sbc_xq`, `sbc`.
2. `bluez5.enable-sbc-xq = true`, `bluez5.enable-volume-sync = true`, and `bluez5.enable-hw-volume = true` are explicitly configured.
3. WirePlumber device rules auto-connect `a2dp_sink` with hardware volume support on matched Bluetooth audio nodes.
4. `tests/test_pipewire_config.py` validates PipeWire clock properties, WirePlumber codec priority order, and AVRCP volume settings.
