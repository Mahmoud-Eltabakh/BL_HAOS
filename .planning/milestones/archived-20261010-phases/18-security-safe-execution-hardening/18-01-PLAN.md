<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP/WebSocket/native integration -> FastAPI routes | Untrusted path, query, JSON, and command values enter privileged control operations. |
| FastAPI/player/manager -> BlueZ D-Bus | Validated device and adapter identifiers select host Bluetooth objects. |
| Player/multi-room manager -> local subprocesses | User-influenced URL, sink, host, and numeric values reach audio/system executables. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-18-01 | Tampering | native command and route validation | high | mitigate | Typed allowlists, canonical MAC validation, bounded fields, and rejection before manager/player calls. |
| T-18-02 | Elevation of privilege | BlueZ manager entry points | high | mitigate | Validate every address/adapter at both API and manager boundaries; resolve only known local adapters/devices. |
| T-18-03 | Command injection | player and multi-room subprocess creation | critical | mitigate | Keep `create_subprocess_exec` argv-only with fixed executables, no shell, bounded sink/URL/identifier values, and tests asserting exact argv. |
| T-18-04 | Denial of service | media URL and process lifecycle | medium | mitigate | URL/field length limits, destination policy, startup/termination timeouts, and cleanup tests. |
| T-18-SC | Tampering | package installation in later dependency plan | high | accept | No package installation occurs in this plan; Plan 02 owns dependency legitimacy/CVE gates. |
</threat_model>
