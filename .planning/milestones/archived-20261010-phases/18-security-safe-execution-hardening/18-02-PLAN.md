<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native integration/Ingress client -> REST and WebSocket auth | Credentials and malformed authorization metadata cross into privileged bridge control. |
| Runtime/config/logging -> diagnostics and support-facing output | Secrets and sensitive failure context can cross into operator-visible channels. |
| Repository manifests/CI -> built add-on image and frontend | Dependency metadata controls code executed with host D-Bus/audio privileges. |
| Add-on options -> host integration and privilege surface | User configuration can influence runtime behavior but must not grant arbitrary host execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-18-05 | Spoofing | native REST/WebSocket authentication | critical | mitigate | Constant-time token comparison, fail-closed token loading, generic unauthorized responses, and malformed-auth tests. |
| T-18-06 | Information disclosure | health/log/error/support serialization | critical | mitigate | Central redaction before persistence/output, bounded details, no raw retry exceptions, and nested secret regression tests. |
| T-18-07 | Elevation of privilege | add-on config and runtime settings | high | mitigate | Fixed privilege policy, bounded config schemas, internal token field, restrictive persistence, and safe fallback defaults. |
| T-18-08 | Supply-chain tampering | Docker/pip/npm dependency inputs | high | mitigate | Exact pins/lockfile, official-source review for added packages, reproducible installs, and blocking high/critical CVE audit in CI. |
| T-18-09 | Denial of service | dependency/build audit and auth paths | medium | mitigate | Bounded payloads/details, deterministic audit thresholds, and explicit failure rather than silent dependency drift. |
| T-18-SC | Tampering | npm/pip/apt installs | high | mitigate | Before any new package install, verify its official registry/source; CI blocks unreviewed drift and vulnerability threshold failures. |
</threat_model>
