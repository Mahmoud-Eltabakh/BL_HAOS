# Plan 06-02: Speaker Management Cards, Discovery Modal & Settings UI

## Goal

Implement the complete React UI component suite: Discovery Modal with live RSSI meters, Speaker Cards with connection toggles and volume sliders, Adapter Status indicators, and Settings Modal.

## Must Haves

1. `SpeakerCard.tsx` rendering speaker name, alias, connection status badge, RSSI icon, assigned adapter, and volume slider.
2. `DiscoveryModal.tsx` scanning nearby devices, displaying signal strength, and one-click pairing.
3. `AdapterStatus.tsx` displaying available Bluetooth adapters and power switches.
4. `SettingsModal.tsx` managing global codec preferences, auto-reconnect toggles, and speaker alias editing.
5. `App.tsx` assembling the complete Home Assistant themed dashboard.
