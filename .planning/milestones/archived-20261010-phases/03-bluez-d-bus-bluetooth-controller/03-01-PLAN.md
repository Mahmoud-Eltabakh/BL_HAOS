# Plan 03-01: Asynchronous Bluetooth Adapter & Device Models with Discovery Scanning

## Goal

Implement the asynchronous Python data models, constants, `BluetoothAdapter`, and `BluetoothDevice` controllers using `dbus-fast` to discover devices, report live RSSI values, filter audio sinks, and manage multiple adapters.

## Must Haves

1. Pydantic models for `AdapterInfo`, `DeviceInfo`, `DiscoveryFilter`, and `AudioProfileType`.
2. `BluetoothAdapter` class with async methods to power on/off, start/stop discovery with transport filters, and query properties.
3. `BluetoothDevice` class with methods to inspect device properties, detect A2DP sink support, track live RSSI, connect, disconnect, pair, and trust.
4. Comprehensive test suite in `tests/test_bluetooth_adapter.py` and `tests/test_bluetooth_device.py`.
