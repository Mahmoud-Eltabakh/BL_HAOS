# Plan 06-01: React/Vite Frontend Scaffolding, Ingress Path Routing & Static Mount

## Goal

Scaffold the React/Vite dashboard structure with strict relative path routing (`base: "./"`), dynamic API and WebSocket connection client, and mount the static frontend in FastAPI.

## Must Haves

1. `frontend/vite.config.ts` configured with `base: "./"`.
2. `frontend/src/api/client.ts` resolving dynamic Ingress base paths for REST API calls.
3. `frontend/src/hooks/useBluetoothEvents.ts` managing real-time WebSocket state synchronizations.
4. FastAPI static file mount in `backend/bl_haos/main.py` serving the web UI.
5. Automated test suite in `tests/test_frontend_assets.py`.
