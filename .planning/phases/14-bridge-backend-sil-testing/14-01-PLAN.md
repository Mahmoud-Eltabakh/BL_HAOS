<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ingress/native client -> FastAPI REST and WebSocket routes | Untrusted callers can attempt device control and receive speaker state. |
| Test-injected BlueZ event -> BluetoothManager event bus | Test data represents external D-Bus state and must be validated through the same serialization path as runtime events. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Spoofing | Native REST/WebSocket authentication | high | mitigate | Add SIL assertions for missing, malformed, and wrong bearer credentials on identity, snapshot, command, and native WebSocket paths; retain one valid-token command test. |
| T-14-02 | Tampering | Native command route | high | mitigate | Assert unauthorized requests do not call `ha_bridge.execute`, and authorized execution is restricted to a configured token and a connected trusted audio sink fixture. |
| T-14-03 | Information disclosure | Native snapshot and diagnostics responses | medium | mitigate | Assert snapshot filtering/normalization and avoid placing credentials in test assertions, event payloads, or response bodies. |
| T-14-04 | Tampering | Mocked D-Bus event serialization | medium | mitigate | Inject only through `BluetoothManager` event seams and assert the WebSocket event envelope and serialized `DeviceInfo` fields. |
| T-14-SC | Tampering | pytest dependency/test execution | low | accept | Use the repository's existing pytest/FastAPI/httpx stack and do not add packages in this phase. |
</threat_model>
