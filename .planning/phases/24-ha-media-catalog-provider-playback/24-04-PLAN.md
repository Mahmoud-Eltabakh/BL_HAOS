## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HA browse response to DOM | Provider titles/thumbnails/capabilities are untrusted display data. |
| User target/item selection to HA service | One explicit available entity and opaque item are the only action inputs. |
| Ingress shell to HA panel route | Navigation crosses the boundary; credentials and catalog requests do not. |
