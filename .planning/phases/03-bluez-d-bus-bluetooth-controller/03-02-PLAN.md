# Plan 03-02: D-Bus Pairing Agent & Central BluetoothManager Lifecycle

## Goal

Implement the BlueZ `org.bluez.Agent1` D-Bus agent for interactive PIN entry and SSP numeric confirmation, along with the top-level `BluetoothManager` orchestrating ObjectManager signals, adapter registry, and device lifecycle.

## Must Haves

1. `BlueZAgent` implementing `org.bluez.Agent1` on `/org/bl_haos/agent` with support for PIN code requests, passkey display, confirmation, and service authorization.
2. `BluetoothManager` coordinating `GetManagedObjects`, `InterfacesAdded`/`InterfacesRemoved`, global adapter registry, discovery events, and device operations.
3. Automated pytest test suites in `tests/test_bluetooth_agent.py` and `tests/test_bluetooth_manager.py`.
