# Plan 01-01: Container Base Dockerfile & S6-Overlay Supervision Scaffold

## Goal

Create the multi-architecture Debian Bookworm Dockerfile, build configuration (`build.yaml`), and S6-Overlay v3 service directory layout supporting system D-Bus and PipeWire dependencies.

## Must Haves

1. Dockerfile builds from `ghcr.io/home-assistant/{arch}-base-debian:bookworm` with PipeWire, WirePlumber, BlueZ, Snapcast, Python 3, and S6-Overlay installed.
2. `build.yaml` declares build targets for `aarch64`, `amd64`, and `armv7`.
3. S6 service `00-init-environment` is registered in `user/contents.d/` as a oneshot service.
4. Automated pytest test suite passes verifying Dockerfile and S6 directory structure.

Define the multi-arch container Dockerfile using Debian 12 Bookworm base image with required system packages:

- `bluez`, `bluez-tools`, `dbus`

- `python3`, `python3-pip`, `python3-venv`, `python3-dbus-fast`
- Audio codec libraries (`libfdk-aac2`, `libfreeaptx0`, `libldacbt-enc2` where available)
