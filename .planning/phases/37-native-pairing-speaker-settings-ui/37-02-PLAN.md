## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HA user → services/WebSocket | Any logged-in HA user could attempt pairing/removal. |
| Integration → bridge | Bearer-token calls to `/native/*`. |
| Bridge errors → HA UI | Error text displayed in panel, options flow, and service errors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-06 | Elevation of Privilege | Services / WebSocket commands | high | mitigate | Admin-only services (`async_register_admin_service`) and `require_admin` commands; SIL non-admin rejection tests. |
| T-37-07 | Information Disclosure | Native token | high | mitigate | Token only in `_headers()`; never logged or returned by `/settings/get`; tests assert absence. |
| T-37-08 | Information Disclosure | Error text | medium | mitigate | Only whitelisted bridge reasons or fixed fallback reach UI/logs; unit tests with unsafe payloads. |
| T-37-09 | Tampering | Settings/PIN input | medium | mitigate | Voluptuous/local bounds mirror bridge models; bridge revalidates. |
| T-37-10 | Spoofing | Legacy routes | medium | mitigate | Client calls only `/native/*`; unit tests assert exact URLs. |
| T-37-SC | Tampering | npm/pip installs | high | mitigate | No new dependencies; any install requires the Package Legitimacy Gate and a human checkpoint. |
