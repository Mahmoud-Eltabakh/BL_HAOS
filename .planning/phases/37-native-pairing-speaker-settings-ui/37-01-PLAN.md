<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Integration → bridge `/native/*` | Network calls carrying the native bearer token trigger BlueZ pairing/connection and settings writes. |
| BlueZ/D-Bus → API response | Low-level error text could leak device paths, MACs, or internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-01 | Spoofing/Elevation | Native management endpoints | high | mitigate | `require_native_auth` first in every handler; parametrized 401 tests and route-inventory test. |
| T-37-02 | Information Disclosure | Error bodies | medium | mitigate | Whitelisted reasons only; tests inject sensitive-looking exception text and assert it is absent. |
| T-37-03 | Information Disclosure | `/native/settings` | high | mitigate | Bounded projection; test asserts `native_token` never serialized. |
| T-37-04 | Tampering | Speaker settings PUT | medium | mitigate | Reuse pydantic validators (`extra="forbid"`, alias/codec/volume bounds); address normalization; 422 with fixed text. |
| T-37-05 | Denial of Service | Concurrent pair/connect | low | mitigate | Preserve `BluetoothOperationInProgress` → 409 with whitelisted text. |
| T-37-SC | Tampering | pip installs | high | mitigate | No new dependencies; any install requires the Package Legitimacy Gate and a human checkpoint. |
</threat_model>
