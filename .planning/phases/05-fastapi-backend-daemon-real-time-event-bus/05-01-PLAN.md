# Plan 05-01: FastAPI Application Core, REST API Routes, Persistent Store & S6 Daemon

## Goal

Implement the persistent configuration store, FastAPI REST API routes for adapters/devices/settings, main application lifespan coordinator, and S6 daemon service `40-bl-haos-daemon`.

## Must Haves

1. `ConfigStore` in `backend/bl_haos/config.py` persisting speaker aliases, auto-reconnect states, and preferences to JSON.
2. FastAPI application in `backend/bl_haos/main.py` with REST router in `backend/bl_haos/api/routes.py`.
3. S6 service `40-bl-haos-daemon` starting Uvicorn server on port 8099 with dependency on `20-wireplumber`.
4. Automated pytest tests in `tests/test_api.py` and `tests/test_backend_s6.py`.
