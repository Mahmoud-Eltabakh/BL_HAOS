<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Home Assistant custom integration to add-on native API | Core sends credentialed REST and WebSocket requests to the add-on. |
| Bluetooth manager to native contract | Raw device records become Home Assistant-visible speaker and device-registry metadata. |
| WebSocket event bus to entity lifecycle | Untrusted network-like event data updates entity cache and Home Assistant state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-04 | S | Native REST/WebSocket bridge | high | mitigate | Require the stable bridge credential for identity, snapshot, and event subscription before data is released. |
| T-09-05 | T | Speaker event payload | medium | mitigate | Validate event schema, normalize addresses, and accept only trusted audio-sink records before changing the cache or adding entities. |
| T-09-06 | I | Device metadata | medium | mitigate | Expose only identity, name, adapter, and connection metadata; never emit the bridge credential in API payloads, events, or entity attributes. |
| T-09-07 | D | WebSocket reconnect | medium | mitigate | Keep one bounded client task per config entry, clean it up on unload, and isolate native subscriptions from the Ingress WebSocket clients. |
| T-09-SC | Tampering | Package installs | high | accept | No npm, pip, or cargo package installation is planned in this plan. |
</threat_model>
