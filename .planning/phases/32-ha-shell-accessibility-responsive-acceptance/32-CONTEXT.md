# Phase 32: HA-Shell Accessibility & Responsive Acceptance

**Status:** blocked pending explicit shell-acceptance authorization

## Discussion

This phase validates the packaged panel inside the actual Home Assistant shell across approved viewport sizes and accessibility conditions. It is not a local mock E2E phase and it does not inherit any live acceptance authority from earlier phases.

## Scope

- actual Home Assistant shell review at 375, 768, and 1440 pixels
- keyboard operation, focus visibility, labels, reduced motion, and contrast
- responsive layout and overflow checks

## Required checkpoint

A reviewer must explicitly authorize the shell inspection and evidence capture before any live validation can be performed.
